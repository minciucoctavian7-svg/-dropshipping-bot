# OTO Market Telegram Bot

Стартовая версия Telegram-магазина.

## Что уже работает
- каталог;
- карточка товара;
- оформление заказа;
- сбор имени, телефона и адреса;
- сохранение заказов в SQLite;
- уведомление администратора;
- раздел «Мои заказы»;
- вопросы менеджеру.

## Запуск на Render

Создайте Worker из этого репозитория.

Build Command:
`pip install -r requirements.txt`

Start Command:
`python bot.py`

Переменные окружения:
- `BOT_TOKEN` — токен Telegram-бота от BotFather
- `ADMIN_CHAT_ID` — ваш Telegram ID

Товар редактируется в `bot.py` в списке `PRODUCTS`.

Важно: SQLite на обычном Render-диске не предназначен для постоянного хранения при перезапусках/пересоздании сервиса. Для рабочей версии с постоянными заказами лучше подключить PostgreSQL.

Также эта версия является Telegram-магазином, а не автоматическим продавцом на Avito/других маркетплейсах. Для такой функции нужны отдельные API/интеграции каждой площадки.
